## 🔧 ¿Qué aprenderás?

- Clonar repositorios.
- Crear y gestionar ramas.
- Realizar commits.
- Subir cambios a GitHub.
- Crear Pull Requests.
- Resolver conflictos.
- Trabajar en equipo sin modificar directamente `main`.

## 📌 Normas de colaboración

Todos los colaboradores deben trabajar en ramas independientes y solicitar la incorporación de sus cambios mediante Pull Requests.
